ACE COMBAT 8 简体汉化 v0.3.0
项目：https://github.com/harei-mu/AC8-Chinese-Mod
下载：https://github.com/harei-mu/AC8-Chinese-Mod/releases/latest
许可证：GPLv3（GPL-3.0-only），第三方依赖保留各自许可证。

仅支持 Windows 10/11 64 位 / 游戏 1.1.2.0 / Steam build 25201480。
使用系统自带的 .NET Framework 和 Windows PowerShell，无需另装 .NET 6/8、SDK、Python 或 Node.js。
安装、卸载、更新和汉化启动均不弹出命令行窗口。
仅限单机。禁止在 ACE COMBAT ONLINE、合作任务、对战或联机活动中使用。
请同时阅读“注意事项.txt”。本项目没有官方授权或免封号保证。

安装
1. 下载 Releases 中的 AC8-Chinese-Mod-v0.3.0.zip，完整解压到普通文件夹。
2. 正常退出游戏。Steam 可以保持运行，也可以保持关闭；安装器不会启动或关闭它。
3. 双击“汉化安装器.exe”。安装器会搜索 Steam 登记的所有游戏库，并读取实际安装文件夹。
   未找到时，点击“浏览…”选择包含 Game 文件夹的 ACE COMBAT 8 游戏根目录。
4. 选择“全部汉化”“界面汉化”或“HUD 汉化”，点击“安装 / 更换汉化”。
5. 首次安装：点击“复制 Steam 启动选项”，到 Steam → 游戏属性 → 通用 → 启动选项中粘贴。
   只需设置一次。已有该入口的用户不需要重复设置。
6. 从 Steam 启动游戏。启动器仅启动单机游戏并加载所选汉化。
   请在游戏中选择简体中文作为文字语言，以保留游戏自带的中文剧情字幕。

选择汉化内容
界面：菜单、设置、训练、机库、资料、战绩、勋章、任务结算及飞机说明等。
HUD：仪表、雷达、普通目标类别、目标名称和战斗提示。
全部：同时安装两项。机炮、导弹、诱饵弹等共用的 HUD 名称随 HUD 组件翻译。
更换内容：退出游戏后再次运行安装器，选择新内容并安装，重新启动游戏即可生效。

普通卸载
退出游戏，打开完整解压包中的安装器，点击“卸载汉化”。
汉化脚本、译文、字体和加载器被移除，游戏恢复原文。
仅保留一个小型原生 EXE 兼容入口和安装记录，它会转交 Steam 的原始启动命令，不加载 MOD。
无需修改或重启 Steam。保留的入口不是后台服务，不会随 Windows 启动。

完全卸载
1. 退出游戏。在 Steam 游戏属性中清除汉化启动选项；若原来设置过其他参数，请恢复那些参数。
2. 从完整解压包中运行安装器，点击“完全卸载”。安装器会关闭自己的窗口以释放 EXE 文件。
3. 完全卸载会移除校验一致的全部汉化文件和兼容入口。自行修改的文件会保留并提示。
   Steam 无需退出或重启。卸载完成后可删除之前解压的安装包文件夹。
4. 若准备联机，请完成这一步后使用 Steam 原始受保护入口，并确认其他 MOD 也已移除。

检查更新
点击“检查更新”查询本项目 GitHub 最新正式 Release；没有新版本时不改动文件。
有新版本时可选择下载安装，或取消。更新会保留已安装的汉化组件。
下载后核对 GitHub 提供的 SHA-256、文件大小、内部清单和版本，校验通过才安装。
更新前退出游戏即可，不重启 Steam。网络失败或校验失败不会开始安装。
手动更新也可以：完整解压新版本，运行其中的 EXE，再次安装。

译名与型号
保留 F-22A、F-14D、F/A-18C 等完整机型编号，台风、阵风、鹰狮等使用常见中文名。
知名英文昵称在空间允许时同时显示；较短的名称缓冲区保留“型号 + 中文名”，
飞机说明中补充对应英文昵称，如“大黄蜂（Hornet）”“超级大黄蜂（Super Hornet）”。
武器代号、坐标、罗盘字母、玩家名称和未经确认的专名保留。

故障处理
游戏版本不符：等待适配新版本的汉化，不修改校验值强行使用。
发现其他 MOD：安装器会停止；请先处理已有加载器或自定义启动器冲突。
部分文本未翻译：记录菜单路径、任务编号和截图，通过 GitHub Issues 反馈。
游戏异常退出：正常退出后完全卸载，恢复原始启动选项，再从 Steam 启动原版验证。
日志位于游戏目录 Game\Binaries\Win64\AC8Chinese\Logs；反馈前检查并遮盖个人路径。
安装、更新和卸载均不覆盖原始游戏 EXE、原始资源容器或存档。
