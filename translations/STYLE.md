# 译文标准

按“信、达、雅”审校：含义准确、表达自然、符合空战游戏语境。HUD 优先简洁可辨，菜单明确操作后果，简报使用自然的军事表述，不为文采增添原文没有的信息。

全部使用简体中文与大陆常用表达。新增译文、复用的游戏原有中文均检查繁体字；字体字形与文字编码分别验证。Windows NLS 审计仅生成候选项，专名和多义字必须按上下文人工复核，不能盲目替换。

- 同一概念跨页面保持一致：机动性、稳定性、出击、任务简报、机体配置、航空母舰、驱逐舰。
- 游戏简体中文资源中已有的地名与任务标题优先复用，记录配对资源键作为依据。自行翻译的行动代号不得标为官方译名。
- 机体／武器型号、武器识别缩写、坐标、数值、按键图标保持原样。普通类别和操作词应翻译。
- 人物、部队呼号按剧情和现有译名核对；不将 Noise 等呼号当作普通词直接翻译。
- 括号、占位符和格式标记必须完整保留。已有中文里的英文按钮名称按精确资源键审校，不能全局替换剧情文字。
- 词条构建成功、运行时命中、画面验证是不同状态；字体缺失、闪烁、截断均不算通过。
- 首帧必须使用中文；“先英文再中文”属于待修复缺陷，不能作为完成状态交付。
- 行动代号 `Operation Showdown` 暂译“决战行动”，属于本 MOD 译文；`Song of Wings` 的“翼之歌”与 `Newfield Island` 的“纽菲尔德岛”有游戏资源内对应中文。
