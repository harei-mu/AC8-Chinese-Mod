# ACE COMBAT 8 简体中文补充 MOD

目标：游戏选项、小地图标注、飞机上方显示名称。独立项目，不将游戏安装目录作为 Git 仓库。

当前状态：资源勘察中，尚无可安装补丁。

游戏路径：`E:\SteamLibrary\steamapps\common\ACE COMBAT 8`

## 工作规则

- 每个完成的修改批次提交 Git，提交前检查差异。
- 原始资源及第三方二进制放在被忽略的 `work/`、`tools/`，构建结果放在 `dist/`。
- 先依据资源键和实际界面判断是否需要翻译，不按英文单词全局替换。
- 已有准确的简体中文保留；修改只覆盖确认过的目标资源。
- 未经游戏内验证，不宣称补丁可用。

## 翻译判定

| 内容 | 处理 |
| --- | --- |
| 设置分类、选项名称、选项值、说明、确认提示 | 翻译，沿用已有官方术语 |
| 地图上的地点、设施、目标类别 | 翻译；地名核对官方译名及上下文 |
| 飞机上方的普通单位名、阵营、任务角色 | 翻译，优先简短、清晰 |
| 飞机型号、武器型号，如 F-16C、AIM-9 | 保留型号 |
| 飞机昵称、驾驶员呼号、编队名称 | 按资源与剧情上下文逐项决定，可用型号加中文昵称 |
| 玩家自定义名称 | 保留 |
| 按键、手柄图标、坐标、单位、无线电频率 | 保留；解释性文字可翻译 |
| HUD 缩写 | 根据含义、官方译法和显示宽度逐项判断 |
| 内部资源路径、键名、占位符、格式标签 | 原样保留，不翻译 |
| 剧情字幕、配音、其他非目标内容 | 本项目暂不改动 |

## 勘察

运行 `node scripts/inspect-containers.mjs "游戏目录"`，生成 `reports/containers.json`。
